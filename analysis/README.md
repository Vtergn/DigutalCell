# 分析目录入口

这个目录保留了长期研究的脚本、报告和中间结果；其中有多条已经判定为 NO-GO 的路线。请先读根目录的[结果索引](../docs/RESULTS_INDEX.md)和[项目地图](../docs/PROJECT_MAP.md)，再进入具体子目录。历史文件暂不批量重命名或移动，避免破坏相对路径、报告引用和数值复现。

当前闭环主线在 [`shape_feedback/`](shape_feedback/README.md)；50 状态电/钙原方程移植在 [`torch_native_port/`](torch_native_port/README.md)。这里的输出以仿真和公开数据再分析为主，真实影像与模拟轨迹没有构成同一细胞的同步力电验证。
