# Duke 数据：压缩阶段的留出细胞预测

日期：2026-09-26。运行 `python analysis/predict_baselines.py` 可复现数值。逐细胞结果在 `baseline_cell_scores.csv`，汇总在 `baseline_summary.csv`。

**范围修正：**`bychannel_approaches.csv` 仅包含每条轨迹约 150 ms 的悬臂压缩阶段。四个通道的代表样本均在这一段结束后才达到电流峰值；此处结果不得解释为完整刺激后的电流波形预测。完整 350 ms 刺激窗口的重做结果见 `full_window_results.md`。

## 任务与方法

输入为 `bychannel_approaches.csv` 的力与功轨迹；目标为同一轨迹的 `absi_blsub_mech`（机械诱发绝对电流分量，pA）。每个细胞只有一条在此汇总表中选出的压缩轨迹。先从测试细胞的前 100 个采样点（约 4 ms、接触前）取得电流中位数作为基线，再预测相对于该基线的变化。因此本实验允许使用测试细胞的**接触前电流校准**，不属于完全无电流观测的零样本预测。

每次留出一个细胞，用同一通道的其他细胞拟合单个非负比例系数。额外运行同一通道与电压分组、以及剔除测试日期所有细胞的训练条件。所有模型只使用机械输入；没有用测试细胞接触后的电流拟合参数。

模型：零响应、正向力比例、正向功比例、固定 5 ms 机械变化代理项（当前力减去因果指数平滑力，再取正值）、该代理延迟 10 或 20 ms、饱和力曲线。表格只列出前四种；其余结果在 CSV 中。5 ms 及延迟均为探索性设定，尚未依据独立数据确定为通道的生物物理时间常数。

主指标为压缩阶段加载开始后的平均绝对误差（MAE，pA）。加载开始定义为力达到该轨迹最大值的 5%。为避免安静区间主导评价，另在真实电流最高的 20% 采样点上计算事件 MAE。事件区间仅用于**评分**，不能用于模型预测。还记录电流 95% 分位的误差。

## 留出细胞结果

下表是每个通道的逐细胞误差中位数，训练使用同通道其他细胞。单位均为 pA；数字越低越好。

| 通道 | 模型 | 全加载 MAE | 高电流事件 MAE |
| --- | --- | ---: | ---: |
| Piezo1，23 细胞 | 零响应 / 力 / 功 / 5 ms 变化 | 12.2 / 31.0 / 28.9 / 29.2 | 40.9 / 52.5 / 37.3 / 42.1 |
| Piezo2，13 细胞 | 零响应 / 力 / 功 / 5 ms 变化 | 67.1 / 83.2 / 90.6 / 85.6 | 233.6 / 179.7 / 188.7 / 131.6 |
| TRAAK，30 细胞 | 零响应 / 力 / 功 / 5 ms 变化 | 17.0 / 22.0 / 19.8 / 24.2 | 51.4 / 39.0 / 33.0 / 34.7 |
| TREK1，34 细胞 | 零响应 / 力 / 功 / 5 ms 变化 | 57.9 / 54.0 / 52.5 / 64.6 | 160.7 / 126.0 / 133.0 / 114.5 |

这些是各模型各自的中位数；判断同一个细胞有没有改善应看配对比较。相对于零响应，力模型降低全加载 MAE 的细胞数依次为 Piezo1 **4/23**、Piezo2 **9/13**、TRAAK **19/30**、TREK1 **21/34**。5 ms 变化模型降低高电流事件 MAE 的细胞数依次为 **19/23、11/13、21/30、22/34**，但它经常增加其余时间段的误差。单一模型还不能同时稳定预测事件幅度和事件外电流。

同电压分组与按日期留出结果也存于汇总 CSV。仅限制在可比电压内，没有消除简单模型在 Piezo1 上的整体失效。按实验日期留出时，以上总体模式仍存在，说明差异不能简单归结为同一天的细胞进入训练集；不过样本量仍小，不能据此确认跨日期泛化。

## 生物物理解读

- Piezo1 的电流具有短暂事件时，持续的力或累积功会在事件外持续预测电流。因此全加载误差甚至高于零响应。一个变化率代理可改善不少细胞的事件区间，但没有解决事件外的假阳性。这提示需要显式建模激活、失活和恢复；**本实验并未证实某个特定门控机制或时间常数**。
- TREK1 与 TRAAK 的较多细胞受益于力或功比例项，说明它们值得作为持续响应模型的起点。但强细胞间幅度差异、保持电压差异与基线问题仍使模型在部分细胞上严重失准。
- 当前机械输入是悬臂力与估计的功，不能直接解释为膜张力或分配到一个离子通道的能量。模型系数也不能读作离子通道电导或蛋白压电系数。
- 这只是 Q1“可预测性”的压缩阶段基线。模型尚未证明能可靠预测独立细胞的完整波形；这些结果不能用于分离膜电容、flexoelectricity 或蛋白压电贡献。

## 下一步最具体的改进

已用四个代表样本核对 `.feather` 与 `approaches.csv`，力和电流逐点一致。下一步以完整刺激窗口建立通道特异的动态模型，在不使用测试细胞接触后电流的前提下，同时优化事件幅度、时间和事件外假阳性。继续按细胞与日期报告误差，并把保持电压及细胞膜电容作为条件变量；这些变量来自接触前实验记录，可以在预测时合法使用。
