# Duke 数据：完整刺激窗口的留出细胞预测

日期：2026-09-26。运行 `python analysis/predict_full_window.py` 可复现结果。逐细胞结果：`full_cell_scores.csv`；汇总：`full_summary.csv`。本报告修正了仅使用压缩阶段 CSV 的早期测试范围。

## 为什么重建窗口

`bychannel_approaches.csv` 恰好保存每个细胞 3,751 个采样点，即约 150 ms 的 AFM 压缩阶段。按照 `bychannel_summary.csv` 的时间，100 个所选细胞中 **95 个的电流峰值发生在这段数据结束后**（Piezo1 22/23、Piezo2 10/13、TRAAK 29/30、TREK1 34/34）。因此只用该 CSV 无法测试完整力电响应。

从每个细胞对应的预处理 Feather 文件中按所选 sweep 读取力、功、已做基线处理的电流与电压。窗口起点由力峰时间确定，为 500 或 750 ms；每段取 350 ms、8,751 点，覆盖压缩及其后的响应。对四个通道各一例进行逐点校验：Feather 里的力与 `bychannel_approaches.csv` 完全一致，`absi_blsub = abs(i_blsub)` 且 `absi_blsub_mech = absi_blsub - offset`，数值差在输出精度内为零。另抽查一例原始 `.asc` 在 500 ms 的电流与电压，经 A→pA、V→mV 换算后与 Feather 精确一致。验证脚本为 `audit_alignment.py`。

在 100 个所选窗口中，电压第 1 至第 99 百分位之差最大为 **0.187 mV**，未见窗口内大幅电压阶跃。不同细胞之间的记录电压仍不同，应作为模型条件变量。

## 第一轮预测设置

- **目标**：`abs(i_blsub)-offset`，并减去测试细胞窗口前 100 点（约 4 ms）的中位数作为接触前电流校准。模型不使用测试细胞接触后的电流拟合参数，所以属于允许接触前校准的跨细胞预测。
- **输入**：同一时间轴上的 AFM 接触力或累计功。测试时允许知道该细胞的机械输入轨迹。
- **留出方式**：每次留出一个细胞，用同通道其他细胞拟合一个非负增益。另试验同电压分组，以及训练时排除同实验日期所有细胞。
- **基线**：零响应、力比例、功比例、固定 5 ms 机械变化代理，以及该代理额外延迟 10 或 20 ms、饱和力曲线。延迟及时间常数是预设探索值，不能解释为已测出的通道动力学常数。
- **评价**：加载开始后的整段 MAE，以及真实电流最高 20% 采样点的事件 MAE。事件位置仅用于评分，不参与预测。

## 结果

同通道留出细胞的逐细胞误差中位数如下，单位 pA，越低越好。

| 通道 | 模型 | 整段 MAE | 事件 MAE |
| --- | --- | ---: | ---: |
| Piezo1，23 细胞 | 零响应 / 力 / 功 / 5 ms 变化 | 43.8 / 156.1 / 145.9 / 63.1 | 202.5 / 234.3 / 131.2 / 187.1 |
| Piezo2，13 细胞 | 零响应 / 力 / 功 / 5 ms 变化 | 70.7 / 78.7 / 93.7 / 83.6 | 217.2 / 130.1 / 115.5 / 184.2 |
| TRAAK，30 细胞 | 零响应 / 力 / 功 / 5 ms 变化 | 36.3 / 33.1 / 35.6 / 36.4 | 68.0 / 42.1 / 42.1 / 63.4 |
| TREK1，34 细胞 | 零响应 / 力 / 功 / 5 ms 变化 | 121.1 / 98.0 / 103.2 / 115.6 | 229.4 / 143.3 / 120.9 / 226.2 |

同一个细胞上的配对比较更稳妥。相对零响应，**力比例**降低整段 MAE 的数量为 Piezo1 6/23、Piezo2 8/13、TRAAK 21/30、TREK1 22/34；**功比例**分别为 4/23、8/13、20/30、23/34。仅看高电流事件，功比例改善的数量分别为 15/23、12/13、27/30、28/34。也就是说，简单机械量携带事件信息，但常在事件以外产生较大误差，尤其是 Piezo1。

固定 5 ms 变化项以及额外延迟 10、20 ms 的版本，均未在 Piezo1 上超过零响应的整段误差；延迟处理也没有形成稳定的跨通道提升。只给当前力乘以一个比例、加一个固定延迟，无法描述这些细胞之间差异很大的时序与幅度。

## 科学解释与边界

1. **可预测性尚未成立为可靠的跨细胞完整波形预测。**静态基线在 TRAAK、TREK1 的多数细胞有益，也能改善多个通道的事件区间；但整段效果不稳定，不能宣称已经得到通用的“细胞力电传递函数”。
2. **Piezo1 的事件强度与持续时间需要分开建模。**静态力/功项可部分命中高电流区，却在其他时刻持续预测电流。5 ms 变化项减少一些长期假阳性，但仍无法稳定预测完整响应。可能需要激活阈值、失活、恢复及细胞特异的通道可用量；目前结果不能识别这些机制各自的参数。
3. **细胞间增益差异很大。**例如在 Piezo1 的 -80 mV 子组，观测电流的 95% 分位幅度在细胞间的第 10 至第 90 百分位约为 101–1,193 pA，而峰值力中位数约 418 nN。相同通道与电压也不能仅凭力预测绝对电流幅度。膜电容可作细胞面积代理，但通道表达量、接触面积及其他因素仍未直接测得。
4. **不可把模型残差称为蛋白压电或膜 flexoelectric 电流。**此数据记录的是电压钳下机械诱发电流，尚无足以单独识别这些项的干预和电极几何信息。模型失配也可能来自通道动力学、接触力到膜张力的映射或预处理误差。

下一步优先检查每个细胞的刺激—电流时间关系与异常样本，再建立有明确激活、失活状态的动态模型；训练和超参数选择只用训练细胞，继续用留出细胞与留出日期评估。
