# 机械敏感性与响应时序：二维扰动审计

数据：[Young 等的 Duke/Dryad 数据集](https://datadryad.org/dataset/doi:10.5061/dryad.gtht76hq5)。分析单位为细胞；跨日期 WT 只作背景。本文延续已冻结的作者逐细胞峰值、接触点和响应判定；未重选 sweep 或调整波形预处理。二维图见 [PNG](sensitivity_timing_perturbation_map.png)，可复算坐标见 [CSV](sensitivity_timing_map_points.csv)。

## 构建体身份审计

作者 README 的构建体定义（本地 `Data/2022_README.md` 第 144、253 行）仅写明 `chimA = Piezo1 with the Piezo2 cap`；[论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9974467/)也将 Piezo1^cap2 作为正式分析的 cap 嵌合体。README 未定义 `chimB`；本地原始 30.8 GB ZIP 和已解压目录均无 `chimB` 原始 Feather 波形，但 `capchims_approaches.csv` 中保留了 chimB 的压缩阶段力、电流和功轨迹。本轮**未能核实 chimB 的蛋白/质粒构型**。因此 A/B 同日比较只能叫两个匿名构建体间的表型差异，不能解释为 cap 对照或 reciprocal chimera。需要原作者构建体记录才能进一步归因。

在 2020-11-08 和 11-10，同日 A/B 的峰值延迟中位数分别为 1.04/3.18 ms 与 0.96/2.20 ms；同日中位差平均 −1.69 ms。日期内细胞标签置换的双侧参考比例为 0.00018。加入日期、log 峰值力和 log 电容后，A−B 延迟系数 −2.14 ms；移除一个 10.8 ms 值后仍为 −1.55 ms。同日工作阈值差异不稳固（置换参考比例 0.152）。这些是两个日期内的**观察性**比较，细胞可能共享盖玻片，处理分配未证实随机。完整结果见 [同日审计](phenotype_positive_result_audit.md)。

## CytoD 的两部分敏感性终点

四个共同实验日期中，DMSO 14/20、CytoD 18/22 个 Piezo2 细胞被标为响应；2020-03-11 两组都无人响应（0/1、0/4）。后三个有响应的日期为 14/19 对 18/18，五个未响应者均在 DMSO；日期内条件分配参考比例 0.031。这里的响应概率同时受通道表达、记录质量、已测试最大刺激和真正阈值影响，不能直接当作通道开门概率。

只看响应者，同日工作阈值的非参数几何平均比值 CytoD/DMSO 为 0.566（日期内置换参考比例 0.013）。对未响应者，逐细胞读取**全部已记录 sweep 的最大 `peakw`** 作为右删失界限；五个细胞中有三个的最大测试工作量大于作者所选 sweep 的 `peakw`。按日期调整的对数正态阈值模型给出：

| 未响应者解释 | CytoD/DMSO 阈值比 | 含义 |
| --- | ---: | --- |
| 5 个全是可用但高阈值细胞 | 0.278 | 全部作为右删失值 |
| 0 个可判定为高阈值 | 0.496 | 全部作为可能表达/记录失败剔除 |

枚举五个细胞的 32 种归属，模型比值范围 0.278–0.496。**这是不同假设的敏感性范围，不是置信区间**；它与非参数 0.566 使用了不同统计量和权重。双方都指向本协议下 CytoD 组较低的响应阈值，但对未响应原因与实验日混杂仍有依赖。2020-03-11 无响应日期无法识别阈值模型的日期截距，因此保留在响应数汇报中、未放进该阈值拟合。详情：[两部分结果](cytod_joint_sensitivity_results.json)、[删失界限](cytod_joint_censor_bounds.csv)。

## 时序与峰后电流：力调整诊断

在三个有响应的共同日期，Piezo2 CytoD−DMSO 的日期内延迟中位差平均 −0.26 ms。响应细胞中以日期、log 峰值力、log 电容调整，Huber 系数为 −0.64 ms；分层细胞重抽 95% 区间 **[−3.00, +0.45] ms**。普通最小二乘受一个 26.96 ms 长延迟影响，系数为 −2.14 ms；去掉该值，Huber 系数为 −0.56 ms。现有数据既不能证明延迟有稳定改变，**也不能证明 CytoD 对时序没有影响**，更不能满足事先未设定的“等效”标准。峰值力来自刺激/响应选择之后，此调整只是描述性诊断。

峰后 20 ms 的有符号电流保留率在 chimA 与 WT Piezo2 间分别约为 0.186 与 0.402。以细胞为单位，并考虑同一时刻全局 AFM 力保留率、log 峰值力和 log 电容，chimA 的保留率差值 Huber 系数为 −0.163，细胞重抽区间 [−0.272, −0.036]；逐一留出日期时方向都为负。但 **chimA 与 WT Piezo2 没有共同实验日期**，该回归无法排除批次/记录差异，也不能把电流下降称为通道本征失活。它只是值得做同日 force-matched 复测的线索。详情：[力调整结果](force_adjusted_phenotype_results.json)、[逐细胞数据](force_adjusted_persistence_cells.csv)。

## 二维图与可成立的结论

横轴是响应者工作阈值中位数的 `−log10(fJ)`（越靠右越敏感），纵轴是 AFM 力峰到电流峰的延迟（越低越快）。A/B 与 DMSO/CytoD 用**各自同日组中位数的箭头**；WT P1/P2 在其它日期测得，以灰色参考点标出。CytoD 未响应者没有虚构的阈值坐标，其响应率与删失模型范围在图上单独注释。不同实验批次的两组箭头不能相互做定量因果比较。

## 追加审计：组别与细胞编号完全分块

进一步按每个日期的细胞编号排序，**四个共同日期均是连续的 CytoD 编号段之后接连续的 DMSO 编号段，没有交错**。编号只是可能的采集顺序代理，不能断言确切时间；但组别和编号段完全重合，因而同日置换参考比例不能视为随机化试验的 p 值。盖玻片、转染批次、实验时段以及操作者随时间变化的操作均可能与处理混杂。两组使用的刺激强度也不同：2020-09-30 的峰值力中位数为 CytoD 44.2 nN、DMSO 127.0 nN；10-13 为 31.9/61.3 nN；10-14 为 31.8/93.3 nN。不同停止时点可能是阈值变化的**结果**，不能仅凭此判定混杂方向，但它说明不同组未在统一力剂量上直接比较。

响应者阈值的日期中位数比值分别为 0.234（09-30）、1.077（10-13）、0.718（10-14）。去掉 09-30 后，余下两天的日期中位数几何平均比值为 **0.879**，而非全三天的 0.566；参数模型的响应者比值从 0.496 变为 0.726。这说明阈值效应主要受 09-30 推动，**不能把 0.28–0.50 当作跨日期稳定的 CytoD 效应大小**。删失情景只针对未响应原因，不消除组别顺序或日期异质性。

相反，嵌合体两个日期的 A/B 细胞编号均有交错：11-08 为 B→A→B，11-10 为 A→B→A→B→A。延迟模型同时纳入日期、log 峰值力、log 电容和线性细胞编号后，A−B 的 Huber 系数为 **−1.58 ms**，按日期和组别重抽细胞的条件区间为 **[−2.80, −0.63] ms**；单独两天也都是负值（−1.88、−1.30 ms）。这增强了“匿名构建体的时序差异”这一描述性结果，但 chimB 分子身份未知、盖玻片分配不明，不能解释为 cap 的特异因果效应。详细数值：[顺序审计](perturbation_order_robustness_results.json)、[条件汇总](perturbation_order_condition_table.csv)。

目前最稳妥的正面表述是：**机械敏感性与响应时序可以分别量化；同日交错编号的匿名嵌合体比较显示稳健的时序差异。CytoD 敏感性信号受一个日期和完全分块的实验顺序影响，需要独立复验。** “部分可分离模块”仍是值得验证的假说，尚不是已证实的跨扰动结论。已发表的 Piezo1^cap2 快延迟结果属于原论文发现。

下一项最有判别力的实验是同一批次、随机化的 WT P1、WT P2、构型明确的 cap chimera 和 CytoD 对照，记录不响应细胞的完整最大刺激，并在共同力范围内测延迟及峰后电流。事先设定时序等效界限，才可能将“CytoD 对时序无明显改变”升级为模块解耦证据。
