# 人源闭环模型外部数据审计（2026-10-07）

> 逐项数值与生理核验现见 `analysis/torch_native_port/COMPONENT_VALIDATION_2026-10-07.md`。其中新发现：当前独立 Land 默认动力学使张力达峰过快；在固定 Ca 输入下改用公开 ToR-ORd–Land 耦合参数可使达峰时间落入参考窗口，但张力峰稍超参考范围。此为隔离实验，尚未做修改参数后的完整闭环预起搏。

## 当前可验证的层级

1. **方程移植与数值正确性：已做。** 固定参数 50 状态 PyTorch RHS 与 MATLAB 实现的 10,100 个导数值比较、两个长度的整搏波形比较见 `analysis/torch_native_port/NATIVE_VALIDATION.md`。这是实现验证，不是生物学验证。
2. **模型内通路消融：已做。** 本地 `analysis/human_feedback_bridge_report.md` 记录 SAC、TnC–Ca 反馈的独立开关，以及相位和求解器容差检查。这是结构检查，不证明真实人细胞的反馈增益。
3. **独立公开实验约束：可做局部验证。** 长度–张力、Ca/力响应、AP/Ca/收缩基线尺度应分开比较，并保留物种、细胞成熟度、组织尺度和观测算子差异。
4. **同一人源个体的校准挑战→封存挑战盲预测：尚无合适的已核实公开记录。** 不能把下面的数据集拼成同一细胞或把收缩运动当作张力。

## 本地模型输出的一个外部检查提醒

当前固定参数模型整搏输出在 `lambda=1.00` 与 `1.10` 时主动张力峰约为 15.79 与 41.93 kPa，Ca 峰约为 0.497 与 0.393 µM。这仅是模型输出。Ballan 的 hPSC-CM 在到 40% 拉伸时报告主动张力增加；其细胞类型、拉伸定义、制备和测量单位与本成人心室模型不同，**不能以两者均上升就声称量级已验证**。这两个模型输出也提示需要系统审查持续拉伸下张力增益和 Ca 反馈的现实性。

### 已执行的定量检查（`analysis/torch_native_port/external_physiology_check.py`）

按照 [BPSLand 2022 表 4 所列人心室体外指标范围](https://www.frontiersin.org/journals/physiology/articles/10.3389/fphys.2022.906146/full)，从本地 1 Hz、`lambda=1.00` 整搏模型曲线独立提取三个指标。两个成人心室模型并非完全独立生物学真值；这里仅把其引用的体外窗口作为生理 plausibility 检查。

| 指标 | 当前模型 | 文献体外范围 | 判定 |
| --- | ---: | ---: | --- |
| APD90 | 265 ms | 180–440 ms | 范围内 |
| 主动张力峰 | 15.79 kPa | 15–25 kPa | 范围内，接近下界 |
| 主动张力达峰时间（相对电压峰） | 100 ms | 147–172 ms | **偏快** |

`lambda=1.00` 的 MATLAB 原实现也给出 100 ms 达峰时间和 15.71 kPa 张力峰；该偏快现象不是 PyTorch 移植造成的。原实现随 `lambda=1.00/1.05/1.10` 变化的张力峰分别为 15.71/25.63/41.80 kPa，Ca 峰分别为 0.496/0.446/0.393 µM；这是同一组固定参数的模型内强度扫描，不能当作人源剂量–响应验证。

`lambda=1.10` 的持续拉伸整搏中，张力峰为 41.93 kPa，Ca 峰为 0.393 µM；电压在本搏结束前未回到由初始静息电位定义的 90% 复极阈值（`APD90 = null`）。这个拉伸条件不能拿来与上表的**静息**成人范围直接比较，但它暴露了现有 SAC/反馈参数在持续拉伸下反应过强的风险，不能称为已经生理校准。人 hPSC-CM 的 40% 拉伸张力峰比约 2.43；模型 10% 持续拉伸张力峰比约 2.66，刺激范围与细胞类型不同，**不作定量拟合或显著性比较**。

本地兔 Dryad 示例中，负载自由与胶内 Fura-2 峰分别约 2.03 与 3.07（比值 1.51）；本模型 `lambda=1.00` 到 `1.10` 的游离 Ca 峰比为 0.79，方向相反。兔子数据的负载模式、物种、观测单位均不同，且档案没有同细胞配对 ID，故这是一个待解释的跨体系差异，**不是严格的反证或效应值比较**。可复算数值保存在 `analysis/torch_native_port/external_physiology_check.json`。

## 推荐的验证顺序

1. 用 Ballan 的公开图/补充材料做**仅限方向与量级范围**的长度–张力检查，必要时索取逐细胞原始记录；不把图像数字化曲线伪装成独立原始个体。
2. 用本地 TTM 特征进行 AP/Ca/运动表型的观测映射范围检查；先为成人模型电压、绝对 Ca、张力与 hiPSC 光学指标定义可比较的特征和不确定范围。
3. 用 Chen-Izu 兔资料与 Nayir 鼠资料检验机械输入引发 Ca/电变化的**方向、时序与是否存在**，明确为跨物种机制 sanity check。
4. 对主要论文 claim 继续保留严格门槛：要验证**个体化人源闭环孪生**，仍需同一样本的已知机械输入、校准挑战、封存挑战，以及事件对齐的 AP/Ca/力或收缩轨迹。现有公开数据尚未核实满足这组条件。
