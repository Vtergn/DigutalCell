# PIEZO2 新数据审计与机械刺激协议设计试跑

## 公开数据能否支撑新的干预感知波形网络

### Nature 2026 force-selectivity 数据

[Mulhall 等的 Nature 论文](https://www.nature.com/articles/s41586-026-10182-7)将 “raw data” 指向 [Zenodo 17644763](https://doi.org/10.5281/zenodo.17644763)。我用 HTTP Range 仅读取 14.9 GB ZIP 的目录索引（约 44.9 kB），没有下载包体。目录共 240 项；去掉 macOS 元数据和目录后，**68 个实际数据文件均是成像类**：61 个 MINFLUX `.mat`、2 个共聚焦 `.nd2`、5 个 STED `.obf`。没有看到 patch-clamp、poking 或逐细胞电流记录文件。见 [完整 ZIP 目录](zenodo_17644763_manifest.csv)和[审计摘要](zenodo_17644763_audit.json)。

因此，该 Zenodo 包很适合研究 PIEZO2 的结构、FLNB 扰动和成像层的机械状态，**并未提供贴文所需的配对、带时间轴的电生理轨迹**。论文附带的 Source Data XLSX 可能含作图数值，但不能把“Zenodo raw data”解释成完整 patch-clamp raw traces。此结论限于公开记录当前列出的文件；不能排除作者在其它未审计位置保存了电生理原始文件。

### Nature Chemical Biology 2026 OSF 数据

[Li 等的 Nature Chemical Biology 论文](https://www.nature.com/articles/s41589-026-02147-8)说 OSF 收录“展示的电生理数据”，对应 [OSF 2CGXN](https://doi.org/10.17605/OSF.IO/2CGXN)。OSF API 当前仅列出一份 402,461 字节的 `Electrophysiology Source Data.xlsx`，已保存到本地 [原始工作簿](../Data/2026_ncb_piezo2/Electrophysiology%20Source%20Data.xlsx)并只读审计。三个工作表分别是：

| 工作表 | 大小 | 实际粒度 |
| --- | ---: | --- |
| Figure 1 | 1,023 行 × 50 列 | 压力与归一化电流的作图曲线，多组数据列；无明确逐样本时间轴 |
| Figure 2 | 65 行 × 3 列 | 0 与 −40 mmHg 下的单通道电流全点直方图 |
| Figure 6 | 28 行 × 14 列 | 各细胞的逆转电位等作图数值 |

论文方法报告了 10 kHz 单通道采样，但 OSF 文件中没有这些 10 kHz 连续记录本身。这个工作簿仍可用于压力敏感性或电导先验，不能直接训练动态波形网络。[OSF 审计 JSON](osf_2cgxn_audit.json)。

**数据选择结论：** 这两套资料均有机制价值，但本次审计没有发现可以替代 Duke 的“机械输入 + 逐细胞原始电流轨迹 + 多种分子扰动”训练集。因此暂不重启高阶网络主线。

## 转向协议设计：六次刺激的合成基准

实现见 [代码](optimal_mechanical_protocol_pilot.py)、[逐细胞结果](optimal_protocol_pilot_cells.csv)、[刺激选择](optimal_protocol_pilot_choices.csv)、[数值总表](optimal_protocol_pilot_results.json)与[对比图](optimal_protocol_pilot.png)。

模拟 50 个细胞，每细胞只允许 6 次刺激；用同一批细胞和同一组逐次测量噪声比较：

1. **固定加载速度、5 s 间隔、递增强度**：借鉴 Duke 采集方式的简化基线，并非重现真实 AFM 协议；
2. **随机多样化**：在预设的峰值力、加载速率和间隔网格上抽样；
3. **信息量驱动**：每次只用过去观测拟合参数，再在候选刺激中选局部 Fisher 信息行列式增量最大的方案，不读取真参数。

模拟的可估量为有效半激活力、峰值延迟、恢复时间和细胞 gain；观测是每次刺激的峰值与峰值时间，最后以一个**未参与拟合**的标准挑战刺激检验预测。力、时间和电流量级仅为方法测试的示例值，**不是 Duke 或 PIEZO 的估计参数**。

| 生成情景 | 方案 | 恢复时间的绝对 log 误差，中位数 | 未来挑战峰值绝对误差，中位数 |
| --- | --- | ---: | ---: |
| 拟合模型正确 | 固定速度/5 s | 0.529 | 0.0981 |
| 拟合模型正确 | 随机多样化 | 0.068 | 0.0132 |
| 拟合模型正确 | 信息量驱动 | **0.059** | **0.0101** |
| 生成模型有偏差 | 固定速度/5 s | 0.529 | 0.1188 |
| 生成模型有偏差 | 随机多样化 | **0.318** | 0.0167 |
| 生成模型有偏差 | 信息量驱动 | 0.344 | **0.0122** |

“模型有偏差”情景把真实刺激–响应曲线宽度从 25 nN 改为 35 nN，并把真实恢复设为快/慢双时间尺度；拟合与设计器仍相信原来的单时间尺度模型。真实比较的关键是**同一动作网格上的随机多样化 vs 信息量驱动**。在正确模型下，信息设计较随机的差异很小，细胞配对重抽区间跨零；在失配模型下，它对未来挑战峰值有小幅改善（配对中位差 −0.0037，95% 重抽区间 [−0.0067, −0.0007]），但对恢复参数**更差**（绝对 log 误差配对中位差 +0.052，区间 [+0.034, +0.070]）。

逐次刺激记录解释了后一结果：信息量设计器主要选力和速度网格的两端，失配情景下只选了 **1/250** 次可用的 50 ms 恢复间隔；随机方案选了 88/250 次。短间隔缺失使双时间尺度恢复更难识别。这个观察为下一版提供了具体改进方向：把模型不确定性与不同时间尺度的覆盖写进设计目标，同时约束刺激强度和实验成本。

## 目前可成立的正面结果

本轮最清楚的正面结果是**刺激协议多样化能在受控模拟中显著增加恢复和未来响应的信息量**；随意增加同类 sweep 无法达到相同效果。信息量驱动选择尚未稳定超越随机多样化，且对恢复模型失配敏感。因此现在适合继续研究**稳健机械实验设计**，不适合宣称已经找到 Piezo 最优协议。下一步要把候选力/速度/间隔约束到真实设备和细胞可承受范围，并用外部数据校准噪声、响应宽度及恢复模型的不确定性；若有前瞻实验，再验证预测增益。
