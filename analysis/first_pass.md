# 细胞力电数据：第一轮核查与探索

日期：2026-09-26。此记录只使用本地公开数据，未重新处理原始电生理波形。

## 研究问题与数据适配

项目第一步应验证：给定 AFM 加载轨迹，能否预测电压钳下的机械诱发膜电流。Duke 数据提供同步的机械与电生理记录；Southampton 数据适合另做电学形变表型分析。两套数据的细胞、刺激和电学终点不同，不能当作同一细胞的两个输出直接拼接。

## 完整性

- `2022_pnas.zip` 包含 3,336 个文件；所有文件已解压，逐个比较的文件大小均与压缩包目录一致。这不是内容校验和验证。
- Duke 解压目录有 `bychannel`、`chimera_experiments`、`cytod`、`mtrek1_tensionprobe`、`stiffness_measurement` 五个分支。
- `bychannel_approaches.csv` 有 375,100 个采样点，恰好对应 100 个细胞的 100 条所选轨迹，每条 3,751 点。`bychannel_summary.csv` 有 100 行、100 个细胞、26 个实验日期。
- `chimera_experiments/capchims_summary.csv` 有 60 行，其中 36 个细胞也在 `bychannel_summary.csv` 中。其余 24 个为 `chimA`/`chimB`。直接合并会重复计数。
- 两份 cytochalasin D 汇总表分别有 56 和 72 行；与上述两个汇总表的 `uniqueID` 均无重合。`stiffness_summary.csv` 有 372 次测量，但来自 75 个文件名标识的细胞，因此其独立样本数不是 372。

## 直接可见的建模限制

1. 四类通道在这些汇总轨迹中的 `velocity` 全部为 40，cytochalasin D 与 chimera 汇总表也全部为 40。这些表不足以做未见加载速度的测试。
2. 保持/阶跃电压不统一。Piezo1、Piezo2 主要在 -80 mV，另有约 0 mV；TRAAK、TREK1 主要在约 0 mV 和 +80 mV。跨通道比较电流幅度时，应纳入电化学驱动力及协议差异。
3. 以细胞为单位计算，峰值力与峰值电流的 Spearman 相关在 Piezo1、Piezo2、TRAAK、TREK1 中分别约为 0.206、-0.258、-0.273、-0.167；峰值功与峰值电流分别约为 0.176、-0.462、-0.214、-0.052。这是**未调整的描述统计**，不能据此否定细胞内的力电转换。每个细胞的通道表达、膜电容、驱动力、接触几何与记录质量可能不同。
4. 同一批细胞中，峰值力与峰值功的相关较高（各通道 Spearman 约 0.75–0.94）。在目前单一加载协议下，单靠拟合优度很难判定“力”和“功”谁是独立的生物物理控制量。
5. 轨迹表的 `absi_blsub_mech` 是 README 所述的机械诱发绝对电流分量。`peaki` 与 `offset` 的含义不同，不能简单地用 `peaki-offset` 代替轨迹目标：它与轨迹最大值的细胞间绝对差中位数约为 51.4 pA。K2P 通道的 `offset` 往往较大，应以预处理流程和原始波形核对目标定义。
6. AFM `force` 是由悬臂测得的接触力，`work` 是处理流程估计的加载功；它们不是直接测得的膜张力或单个离子通道吸收的能量。不能把模型系数直接解释成蛋白的材料常数。
7. 电压钳数据直接测量的是电流，不提供自由演化的膜电位；本数据也没有可单独识别膜 flexoelectricity 或蛋白压电贡献的对照。因此第一阶段可测试预测性和部分通道/细胞骨架效应，不能仅凭残差命名为压电电流。

## 后续计算实验

1. 核对所选轨迹与对应原始 `.asc`、预处理 `.feather` 的时间对齐、采样率、刺激区间和目标电流定义；抽查各通道及异常延迟样本。
2. 做细胞级划分，并另做按实验日期划分的压力测试。建立简单基线：细胞内基线、力/功的静态曲线、带时延的动态模型。只在独立细胞上报告预测误差及不确定性。
3. 先在通道内、可比电压条件下测试，再做跨通道测试。把膜电容、保持电压、噪声、接触力范围和日期作为记录条件，检查它们是否解释模型错误。
4. 分析 cytochalasin D 与对照时，先比较力范围、保持电压和实验日期。两组的峰值力分布可明显不同，未经匹配的电流中位数差异不能当作药物的因果效应。
5. Southampton 工作簿以论文图表数据为主。先独立审计其逐细胞配对信息，再确定能够验证哪一种形变—电学映射；目前不能预设它提供原始多频阻抗时间序列。
