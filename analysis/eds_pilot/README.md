# EDS 可辨识性首轮闸门（2026-10-11）

## 研究问题与来源

检验少量频率的红细胞 electro-deformation spectroscopy（EDS）是否保留膜相对介电常数、胞质电导率及膜剪切模量的信息，以及模型失配会怎样改变结论。物理起点为 [Du et al., *Acta Biomaterialia* 2025, DOI 10.1016/j.actbio.2024.12.012](https://pmc.ncbi.nlm.nih.gov/articles/PMC12453691/) 的单壳 Clausius–Mossotti 公式（Eq. 4）、椭球去极化因子（Eq. 5）、介电泳力（Eq. 7）与膜力平衡（Eq. 11）。原文测量 100 kHz–15 MHz，固定胞质相对介电常数 59、膜电导率 10⁻⁶ S/m；介质电导率为 0.01 S/m。原始逐细胞数据和作者拟合代码未在论文中公开，论文注明数据可向作者索取。

## 实现的两层模型

1. `model.py`：Eq. 4 的**球形特例**，读取量简化为 `Re(f_CM)/μ`。这样可以快速检验频率信息与力场增益的结构对称性。假设介质相对介电常数 78、细胞半径 3.9 μm、膜厚 4.5 nm；球形和变形读出均为本研究假设。
2. `ellipsoid_check.py`：实现 Eq. 4/5/7/11 的椭球受力平衡。原论文实际逐频测量长、短轴，再由体积求第三轴；为了实现真正的前向预测，这里额外设定横轴按 `λ⁻¹ᐟ²` 缩放，使体积守恒。**此闭合关系不来自原文，不能称为精确复现。**

## 已完成的可复核检验

- 椭球模型在 7 个频率下生成长轴伸长比 `λ=a/a₀=1.014–1.290`，同模型无噪声逆问题回收输入的 `(ε_mem, σ_cyto, μ)=(4.7,0.65,2.5)` 至数值精度；体积变化小于 `5×10⁻¹⁶`。这只验证代码的内部一致性。原文表 1 的 ESF 是 `a/b`，**不能直接与此处的 `a/a₀` 比较**；在所选平衡横轴闭合下，峰值 ESF 约 `1.29^1.5=1.46`，接近但尚未按真实逐细胞数据定标。
- 21 点完整频谱的 3 参数局部 Jacobian 奇异值为 `205, 51.7, 6.88`（按假设噪声标准差 0.0075 归一化），条件数约 `29.8`。因此在**已知力场增益、固定模型、当前参数附近**，三参数局部满秩。
- 若把电场力的未知乘性增益 `g` 也作为参数，读出为 `g Re(f_CM)/μ`；`∂y/∂log g = -∂y/∂log μ`。四参数 Jacobian 的最小奇异值约 `3.8×10⁻¹³`。因此不独立标定场强，任何频率数都不能单独识别 `μ`，只能识别 `g/μ`。
- 80 个合成细胞，固定随机种子，三个参数分别在 `[2,8]`、`[0.3,1.1] S/m`、`[1.5,4] μN/m` 上均匀抽样；21 频点先生成一次独立高斯噪声，再让所有设计使用同一细胞及对应频点的相同噪声。指标为三参数平均绝对 log 比误差，每个细胞先平均，再汇总中位数与第 90 百分位数。噪声为绝对响应单位 `0.0075`，尚未由真实 EDS 噪声定标。

频率从 100 kHz–15 MHz 的 21 点候选集中选取。D-opt 在名义参数处最大化 log det(`JᵀJ`)，未接触测试细胞；不含设计后调参。完整频谱中位误差最佳，稀疏 4–5 点接近，但胞质电导率仍相对较弱。单一膜电导率失配下，完整频谱尾部误差可能更大，这只是当前简化模型的提示，不能据此断言稀疏频谱通常优于完整频谱。

## 决策

**有限 GO：继续做经真实形态和场强校准的完整前向模型；暂不宣称已找到 model-robust 压缩频率。** 首轮已经排除“任意三点都和全谱一样好”的简单情形，并发现必须解决的场强–剪切模量结构不可辨识。真正的下一关是获得或重建逐频椭球轴长和场强校准，固定一个独立的测试群体，再检验不同膜力学形式与几何误差。没有这些约束，所谓 robust OED 会优化一个尚未得到实验支持的代理。

后续椭球模型、模型失配和双电场强度实验见 [DUAL_AMPLITUDE_REPORT.md](DUAL_AMPLITUDE_REPORT.md)。其结果将设计问题具体化为“频率与电场强度如何共同提供力学可辨识性”。

## 复现

在项目根目录运行：

```powershell
python analysis/eds_pilot/ellipsoid_check.py
python analysis/eds_pilot/run_gate.py
```

结果写入 `results/ellipsoid_consistency.json`、`results/gate.json`、`results/per_cell_errors.npz` 与 `results/gate.png`。`analysis/eds_source.xml` 是 Europe PMC 下载的论文全文 XML，用于核对公式和参数；不是原始实验数据。
