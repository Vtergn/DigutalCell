# 干预感知因子化网络：一次小规模可证伪试跑

目标：检验“稀疏干预潜变量”是否比简单低维基线更能找回机械转导的功能因素，并在 Duke WT 波形上跨实验日期稳定重建。代码：[试跑脚本](factorized_latent_feasibility.py)；数值：[JSON](factorized_latent_feasibility_results.json)、[真实数据逐 sweep 留出误差](factorized_latent_real_held_date.csv)。

## 设计与边界

合成实验中，180 个模拟基础细胞各有 4 条**配对**记录：对照、阈值降低、响应延迟缩短、峰后衰减加快。基础细胞随机分为训练 120、测试 60，测试细胞及其全部干预记录完全留出。合成电流由机械斜坡、阈值交叉、延迟、衰减常数和随机 gain 产生，并有测量噪声。已知四个真因素：阈值、延迟、衰减、gain。网络压缩为四维潜变量；比较 PCA、普通自编码器、干预配对的稀疏且方向分离自编码器，并分别测试只看电流、同时看机械力/累计功的版本。稀疏约束不事先规定哪一个潜变量属于哪一个干预，但**假定三种干预应有不同方向**。这一假定只在明确如此生成的合成数据中使用。

真实数据沿用此前冻结的有符号电流 QC、AFM 力峰对齐和峰值归一化。进入试跑的是 WT Piezo1/Piezo2 各 11 个细胞、共 61 条 sweep；训练时同一细胞的多条 sweep 尚未严格等权，但最终指标先在细胞内、再在日期内平均。每轮完整留出一个日期，共 11 个日期。当前自编码器**把已观测电流输入编码器**，所以这是后验波形表征稳定性检查，不是力到未来电流的预测；也还没有连续隐藏状态或 history 模块。真实数据没有细胞跨干预配对；CytoD 条件又与细胞编号段完全重合，故不把真实干预标签放进稀疏训练损失，也不宣称已完成真实数据的留出干预预测。

## 合成测试：潜变量更集中，但没找回三个独立扰动

| 模型 | 留出基础细胞的波形 RMSE，越低越好 | 潜变量与真因素的匹配 Spearman，越高越好 | 三种干预实际占据的主要轴数 |
| --- | ---: | ---: | ---: |
| 四维 PCA | **0.171** | 0.371 | 2 |
| 普通四维电流 AE | 0.237 | 0.446 | 2 |
| 配对稀疏/正交电流 AE | 0.229 | 0.421 | 2 |
| 机械条件 PCA | **0.170** | 0.413 | 2 |
| 普通机械条件 AE | 0.255 | 0.532 | 1 |
| 配对稀疏/正交机械条件 AE | 0.241 | **0.542** | 2 |

最关键的失败并非 RMSE：即便合成真值**确实由三种不同干预生成**，这次机械条件稀疏模型仍把阈值与延迟变化归入同一个主轴。机械条件稀疏 AE 的真因素相关仅比同容量普通 AE 高 0.010，且波形重建比 PCA 差。合成数据仍是简化刺激和电流方程，不能替代实验真值。

另外固定同一批模拟细胞及训练/测试划分，只改变网络初始化做了三个种子。机械条件稀疏模型的真因素匹配为 **0.542、0.431、0.426**，相应普通 AE 为 **0.532、0.555、0.515**；稀疏模型分别使用 2、3、3 个主要轴。后两个种子即使形成了三个不同方向，**与真实因素的对应反而更差**。可见“扰动方向看起来正交”本身不是因子恢复的证据。详细记录在 [JSON](factorized_latent_feasibility_results.json) 的 `conditional_synthetic_three_seed_check`。

## Duke WT：跨日期没有优于 PCA

| 模型 | WT P1：8 个留出日期的日期均值 RMSE | WT P2：3 个留出日期的日期均值 RMSE |
| --- | ---: | ---: |
| 四维 PCA | **0.0566** | **0.0449** |
| 普通四维电流 AE | 0.0576 | 0.0453 |
| 机械条件 PCA | 0.0707 | 0.0499 |
| 机械条件 AE | 0.1080 | 0.0709 |

误差单位是“按本 sweep 观测峰值归一化的电流”。机械条件 PCA 在小样本下因先拟时间点上的力/功响应而更差；机械条件网络参数更多，留出日期退化明显。不同基线的参数量和输入不完全相同，不能由此断言任何神经状态空间方法都无效；能断言的是**这次实现没有达到继续解释 Duke 潜变量的门槛**。

## 对创新路线的实际判断

目前可以保留“跨机械协议识别可分离功能因素”作为**方法研究题目**，但不能从这组 Duke 干预数据直接训练并验证它。这里存在两个具体障碍：真实干预缺少同一细胞前后配对或交错随机化；现有加载协议对阈值变化与延迟变化产生相似的电流时移，即使合成有真值，简单的稀疏因子化也会混淆。引入更丰富的加载速度与力幅度，可能比增加网络层数更有信息量。

下一轮若要继续这条路线，最低通过条件是：在**不同模拟物理协议与多随机种子**中，留出干预的真因素恢复明显超过 PCA 和同容量普通 AE；再用有交错/配对、同类机械输入和电流输出的外部真实数据检验。未达到这些条件前，不把真实网络 latent 的变化解释成已发现的分子模块，也不以“高阶网络”作为论文贡献。
