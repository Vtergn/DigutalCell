# 最小真实人源机械挑战接口（方案，不构成已有验证）

目标：在可追踪的同一人源心肌细胞或同一微组织上，获取**基线 → 校准挑战 → 封存挑战**的时间同步记录，检验“挑战后邻居更接近未来功能”这一预注册指标。

可机器读取的三个表定义见[JSON schema](real_mechanical_challenge_schema.json)。

## 必需记录

| 层级 | 字段 | 作用 |
|---|---|---|
| 样本 | `sample_id`、分化/培养批次、成熟度指标、细胞或微组织类型 | 按独立样本分组；不把同一样本的搏动当独立个体 |
| 激励 | 起搏时间戳、周期、刺激幅度；药物/温度 | 固定电状态，记录潜在混杂 |
| 机械输入 | 实际肌节长度/应变或力的逐时轨迹、控制模式、探针/基底几何 | 区分长度钳制、力钳制和后负荷；记录实际输入而非指令值 |
| 输出 | 与输入同一时钟的膜电压/AP、游离胞质 Ca、张力/收缩力及质量标记 | 建立共同观测层；至少 AP、Ca、力三者中两者同步 |
| 序列 | 每条件前的稳态搏数、挑战顺序、恢复间隔、重复刺激编号 | 识别顺序漂移、疲劳和机械历史 |

主验证单位为**独立样本**。固定基线和一次机械校准挑战，第三个挑战在分析前封存；随机或平衡校准/封存条件次序，在足够恢复后采集。主终点预先固定为封存挑战的 APD、Ca 峰与张力峰及波形距离。邻居数、可测分辨下限、缺失和未复极的处理规则须在解封前写定。

真实验证必须同时报告输入轨迹可重复性、AP/Ca/力三通道信噪比、未复极或不规则搏动比例，以及按样本而非搏动重抽样的置信区间。现有 TTM 数据没有匹配的逐样本机械校准与封存挑战，因此不能用于这一主验证。
