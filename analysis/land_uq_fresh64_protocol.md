# 预先固定的 64 细胞预测区间确认方案

在读取此批细胞的 λ=1.125/1.15 目标张力评分前固定：

1. 从尚未用于此项目 UQ 确认的 synthetic test cells 中按种子 20261004 选择 64 个。合成低噪声观测和原定 Savitzky–Golay 处理保持不变；Ridge、五参数 Land 点拟合、γ=0.1 均冻结。
2. **只凭观测到的 λ=1.1 张力峰值**分四个等人数档，档内固定种子随机分成校准与评价各 8 个，共 32/32。具体行号在 `land_uq_fresh64_manifest.json`，目标评分脚本不得修改它们。
3. 每细胞在完整 8 参数 Land 空间提出 **24 个**候选，以两个已观测负载的拟合误差赋权；候选不得读取目标张力或真实参数。候选加权均值作为中心、候选标准差与 0.5 kPa 下限的较大者作为时变尺度。
4. 比较冻结的点孪生时变残差基线。各方法用校准细胞自己的整条波形最大标准化误差，以 32 个分数中升序第 30 个构造名义 90% 同时预测带。评价细胞只用于最后评分。Lower band 可裁剪到 0 kPa。
5. 主终点分别在 **两个**目标 λ=1.125、1.15 检查：完整波形覆盖至少 29/32，且机制集合的平均区间宽度与 interval score 均低于点孪生时变残差基线。32 个评价细胞的覆盖率估计很粗；即使通过，也只能称独立 synthetic 确认，不能称真实实验保证。
6. 若任一目标覆盖低于 29/32，则不宣称可靠的 90% 预测区间；保留宽度/评分的描述性结果并停止同批细胞上的区间规则调参。高噪声扩展须待此关通过。

这套规则限定在同一 ToR-ORd→Land 模拟器、相同低噪声机制与固定机械负载；它不检验跨模拟器或真实人心肌细胞的概率校准。
