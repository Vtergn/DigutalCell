# 单细胞力电仿真器：BETSE 参考与第一版边界

日期：2026-09-26。本文是研究架构说明，不是已验证的膜张力、通道开放概率或自由膜电位模型。输入为 Duke 实验的 AFM 机械轨迹和记录条件，主要可检验输出为同一细胞未来刺激的电压钳电流峰值、响应时间及波形。

## 从 BETSE 借鉴什么

Pietak 与 Levin 的 BETSE 论文图 1 用膜电容、膜通透通路、泵电流与细胞间通路画出直观的“生物电路”。论文的实际求解比这张图丰富：追踪多个离子的电扩散、浓度、电荷、膜内外电位及细胞间连接；图 2 是细胞与外液网格。其验证包括已知离子通透条件下的静息膜电位与 Nernst/Goldman 等独立约束。参见用户提供的 Frontiers 论文，尤其第 3–5、9、11–13 页。

本地 `D:\MyProjects\SP坐标系\betse` 的 README 将其定位为二维多物理场组织模拟器；`betse/science/sim.py` 管理细胞、外液、电位和传输状态，`betse/science/channels/channelsabc.py` 定义通道接口。`betse/science/physics/deform.py` 处理细胞群受压力、电场等作用的形变，并不等于 Duke 单细胞 AFM 压入到 Piezo 局部膜张力的已验证转换。BETSE 的 BSD 2-clause 许可证允许参照或复用，但第一版项目宜先独立、轻量实现；若复制源代码，保留许可证和原版权声明。

## 与 Duke 数据相符的系统框图

```mermaid
flowchart LR
    U[AFM input F(t), indentation proxy d(t)] --> X[Effective mechanical load z(t)]
    X --> H[Cell-specific response threshold Fth]
    H --> E[Event and temporal shape q(t)]
    U --> A[Stimulus intensity ratio rF or rW]
    K[First responsive sweep: Ical, Fth] --> H
    K --> A
    A --> P[Peak amplitude Apeak]
    E --> J[Controlled mechanoelectric current Imech = Apeak q(t)]
    P --> J
    V[Measured holding voltage Vhold] --> C[Voltage-clamp observation model]
    J --> C
    C --> Y[Predicted patch current]
```

这里 `z(t)` 可先取**测得的 AFM 力代理**，不预先声称它是局部膜张力。`q(t)` 的峰值归一化为 1，只由训练数据与测试机械轨迹生成，不能用测试电流峰值做归一化。第一版中，阈值、幅度、时间形状是明确分开的模块；对 Piezo2，可将当前整日期留出中表现较好的力幂律 A2 作为幅度候选，对 Piezo1 仍以线性力幅度 A1 为保守基线。时间形状先用力阈值模型，适应态仅保留为待检验候选。所有模块组合后仍需重新做整日期留出，单个模块各自有效不保证联合波形有效。

## 概念电路应区分两种实验模式

**Duke 现有电压钳数据：**在持有电压近似固定、基线和钳制瞬态处理后，观测量是机械刺激诱发的电流。第一版电路可表示为膜电容 `Cm`、漏电通路与**机械控制电流源**并联，在 `Vhold` 下预测 `ΔIpatch(t)` 的大小和时间。这里的受控电流源是对可观测输出的工程化封装，并未声称已经知道单通道电导或开放概率。

**未来自由膜电位仿真：**若要改用机械控制电导，形式可写为 `Imech=Gmax·Popen(z)·h(t)·(Vm−Erev)`，并和 `Cm dVm/dt = Iext−Ileak−Imech−...` 耦合。这是待检验的模型扩展。仅凭固定电压下的电流幅值，`Gmax`、`Popen` 与驱动力 `(Vhold−Erev)` 可互相补偿；`Cm` 也不能从机械电流波形单独辨认。要让等效电路具有电导与膜电位的生物物理解释，需要多持有电压的 I–V／反转电位、膜电容及漏电流测量，并明确钳制误差与电流方向。当前预处理采用电流绝对值，适合预测幅度，却不适合直接反演带符号的电导。

## 模块、证据与可辨识性

| 模块或参数 | 当前证据 | 第一版如何处理 | 还需要什么验证 |
| --- | --- | --- | --- |
| 细胞响应阈值 `Fth,i` | 首次校准可获得；帮助定位未来事件时序 | 细胞特异的 AFM 力阈值代理 | 对未响应细胞及其他加载几何的外推 |
| 幅度比例 `Apeak/Ical` | Piezo2 的跨日期力幂律优于线性；Piezo1 增益不稳 | Piezo2 A2；Piezo1 A1 基线；标明估计不确定性 | 新日期／新细胞验证、响应与不响应联合建模 |
| 时间形状 `q(t)` | 简单力代理可定位 Piezo2 峰值；相对峰后衰减尚未稳定转化为绝对波形预测 | 先作为经验时间编码，不固定失活常数 | 独立留出波形、相同幅度尺度下的峰后误差 |
| 黏弹参数 `k, η` | 有 AFM 力、悬臂位置、压入量代理 | 可单独检验 AFM 力–压入曲线；不把拟合值直接叫膜张力 | 压入几何、接触、力松弛和重复速度实验 |
| 有效膜负载 `z(t)` | 没有局部膜张力直接观测 | 潜变量，仅作 AFM 机械代理 | 局部膜张力/形变或独立的力传递测量 |
| `Popen, Gmax, Erev, Cm` | 固定电压的电流及部分元数据无法联合唯一决定 | 不在第一版声称参数已测得 | 多电压 I–V、反转电位、单通道/表达量、膜电容 |
| 机械松弛 vs 通道适应 | 二者都能造成峰后下降，旧 M2 前瞻预测不稳 | 作为可替代的机制假说 | 速度、保持时间、释放及恢复刺激的正交操控 |

Kelvin–Voigt `F=kx+η dx/dt` 或标准线性固体可以作为**AFM 接触力学子模型**，但拟合出 `k,η` 只说明宏观力–位移曲线能被描述，不能自动给出局部膜张力 `T_eff`。若在电流模型中再加入任意可调的力传递增益、sigmoid 门控、开放概率和适应态，在目前的单电压、固定加载速度数据上会出现多组参数产生近似相同电流的不可辨识性。必须先展示各个新增状态在未参与拟合的数据上带来独立预测增益。

## 工程实现顺序与验收

1. **可复现的观测级原型。** 明确输入单位和时间基准：`F` 为 nN、压入代理为 nm、`Vhold` 为 mV、电流为 pA；按现有脚本读入首次校准及未来 AFM 轨迹。输出 `event`、`Apeak`、`q(t)`、`Ihat(t)`，每个模块同时返回其参数来源和是否使用测试电流。先以 A1/A2 幅度及力阈值时间形状复现已完成的留出结果。
2. **接入电压钳观察层。** 把 `Ihat(t)` 表示为可控电流源；保留以后切换为 `Gmech(V−Erev)` 的接口，但只有测得反转电位和电压依赖后才为其参数赋生物物理含义。验收项目包括单 sweep 电荷/峰值时序、整日期留出误差、未响应 sweep 的误报，以及参数单位与电流符号。
3. **逐个加入可被区分的物理模块。** 先单独验证 AFM 力–位移/松弛子模型，再比较机械滤波与通道适应对峰后电流的**不同预测**。CytoD 与 chimera 放在参数冻结后的外部机制检验中；扰动可能影响多个参数，不预设唯一归因。
4. **获得新测量后扩展。** 若增加多电压、不同加载速度/保持时间、局部膜张力等，才升级到机械控制电导、自由膜电位和更细的通道动力学。多细胞、缝隙连接与电扩散属于后续研究尺度，不能由 Duke 单细胞电压钳数据验证。

因此项目的工程定位可以是 **data-calibrated single-cell mechanoelectric simulator**。这比现阶段宣布一个已识别的弹簧–通道–RC 参数集合更准确：系统框图清楚、观测预测可复现、各模块能被未来实验逐步替换。

后续论文路线与波形拓扑分析的分工见 `mechanistic_tda_roadmap.md`：仿真器负责未见刺激预测，波形几何帮助寻找仍未解释的变化方向，扰动和新实验负责检验机制解释。
